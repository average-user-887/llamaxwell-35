# Exact shared gate/up weight rows in two-token verification

The candidate targets the native one-proposal verifier on Quadro M6000, two input rows of width 2,048, all eight routed experts and the shared expert. The current matched 80K one-slot measurement is 92.0067 tok/s native versus 76.6949 serial. At its measured yield, closing the 25% gap requires about 0.82 ms per proposal or 20.5 µs per layer if all forty layers contribute equally.

## Preregistered decision

Run the actual two-row GGML MoE graph with current cohort and candidate dispatch selected per batch in the same binary. The candidate passes the operator materiality gate if both partial-overlap mirrored pairs save at least 30 µs per layer and neither disjoint pair regresses by more than 5 µs per layer. The thresholds are inclusive. The synthetic partial fixture has five routed experts in common, including four at different ranks. Disjoint and partial inputs use distinct activations in both rows. Real-model route overlap and end-to-end gains are unknown.

Require 4,096 finite output words bit-identical to the unchanged cohort control per fixture and a second bit-identical candidate round. Check all sixteen ordered expert IDs separately against the CPU fixture, generic GPU router, current cohort readback and both candidate readbacks. Refuse timing on a numerical/readback failure or insufficient physical residency. Each process requires 24 SMs, two active 512-thread CTAs per SM, zero local bytes and the frozen registers/shared-memory sizes. Check real path and paired-callback counts for each graph and timed batch. Disable CUDA graphs to exercise the actual graph matcher and schedule each time.

Warm both paths for eight synchronous full graph calls each. Time 96 synchronous calls per interval. Run control/candidate/candidate/control on disjoint routes and the reverse order on partial routes. Save each duration, both paired differences and the forty-layer projection per fixture. Treat each projection as an operator extrapolation. The operator does not contain GDN, target head, attention, draft or server work.

## Kernel layout

Phase A retains the original normalization, router arithmetic, 24 CTAs per token and scratch. A full 48-CTA fence/barrier makes both rows' router partials visible. Each CTA calculates the peer normalization with the original 256-thread accumulation and reuses space reserved for Phase C. Warp ballots compact the routed intersection in row zero's order and each token's unmatched ranks. Rank indices survive until intermediate scatter. Slot zero always contains the separate shared expert.

Two neighboring warps in one CTA own the same intermediate channel. One warp loads the full 1,152-byte Q4_0 gate row and its partner loads the full up row, each through the original coalesced 72-uint4 staging routine. Both read the same weight tiles with their own normalized token activations, unchanged dot2c arithmetic and the original butterfly sum. A lane-zero writer stores each result into that token's original expert-rank/channel slot. Unmatched ranks run in their private cohort using the existing gate/up staging and prefetch. Zero routed overlap leaves one shared group and eight solo ranks per row. Full overlap leaves nine shared groups and zero solo ranks. A full-grid fence/barrier protects the original down projection, residual and ordered weighting. No model data is substituted or dropped.

The CPU schedule fixture enumerates every destination and unique conceptual gate/up tile for overlaps zero through eight with rank permutations and both token orders. The full physical harness separately uses a seeded real GGML router and the exact cohort kernel. The control relink matches library 19607daf02bc6dcd722a0695787046db9b4c6b8e010545598d3ad60649d68d00. Its original 17 device functions compare byte for byte across 46,032 instruction words. Both links retain the exact Q8 GDN object. Build metadata, flags and binary digests are pinned. The new kernel uses 63 registers, 272 static and 39,424 dynamic shared bytes with zero local stack or spills. CPU compilation alone does not establish physical residency or speed.
