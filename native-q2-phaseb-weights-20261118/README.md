# Exact cross-token MoE weight reuse

18 November 2026. A fresh Astra 6.2 card implemented a two-row sm_52 Phase B schedule that loads matched gate/up weight rows once per shared or intersecting expert. Each token retains its own FP32 accumulator and original expert rank, including four permuted common ranks in the five-overlap fixture. The original down projection and all eight experts remain. A deterministic CPU fixture exhausts overlap counts from zero to eight, each with rank permutations and both token orders. The candidate preserved all 17 prior device functions and the existing Q8 GDN object.

The actual standalone operator passed all bitwise output, repeat, route, physical dispatch and occupancy checks. It regressed **20.14–22.81 µs per layer** on the independent fixture and **10.33–11.05 µs per layer** with five common experts. The preregistered thresholds were no more than 5 µs regression in either independent mirror and at least 30 µs savings in both partial mirrors. Both thresholds were missed. The exact candidate did not advance to the whole model.
