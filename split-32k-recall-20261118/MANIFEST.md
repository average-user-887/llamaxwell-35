# Package manifest

| File | Contents |
|---|---|
| `README.md` | Fresh matched 32K timings, an independent 80K recall verdict, and reproduction settings. |
| `evidence.json` | Allowlisted source/runtime fingerprints, scalar measurements, typed settings, and comparison verdicts. |
| `SHA256SUMS` | SHA-256 checksums for the README, evidence, and manifest. |

The allowlist covers public commits, source/model/image/binary/input and receipt fingerprints, GPU model and architecture, typed server settings, bounded workload and cache counts, draft and offload counts, observed dispatch widths, timing and rate scalars, wrapper status, and equality, mismatch-position and recall verdicts. The short recall output comparison is represented by its equality verdict.
