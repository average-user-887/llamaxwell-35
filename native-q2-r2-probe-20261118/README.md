# Exact tile-four two-row sparse probe on Quadro M6000

Both fixture orderings saved 10.68 µs per 81,920-key whole-operator call against the fast selector. The preregistered 30 µs threshold failed. This experiment ends at the operator. The 8,192 output words were finite and byte-identical across all four processes. Both candidate processes compared raw scores, 1,280 metadata entries and four plans against the original scan. Each adversarial mask exercised 12 invalid-mask and 12 invalid-score blocks. The numeric block indices in the traces refer to the fixed synthetic fixture.

Run `python3 -B replay.py` to verify all public numeric traces and the gate. The cross-process output comparison used the local arrays. RELEASE.md describes the original freeze.
