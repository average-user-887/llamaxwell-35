# Evidence and reproduction

- `operator.log` contains every typed synthetic numeric comparison, residency observation, runtime digest and measured event interval. `result.json` and `status.txt` record the comparison and terminal statuses.
- `candidate.patch`, `occamy-gdn.cu`, `envelope.inc` and `prepare.py` contain the exact diagnostic source. The regular graph matcher cannot select this treatment.
- `build.json`, `build.log`, `actual-source-and-runtime-pins.json`, the compile recipe, and the compressed SASS hold build and device-code evidence. The compile and build templates and log display replace the local source prefix with `<EXACT_SOURCE_MOUNT>`. Before reproducing an exact binary, substitute the source mount corresponding to the pinned CMake response files. Preserve the input object order, pinned CUDA 12 build image, flags, response files and original object manifest.
- `first-elision-compile.log`, `peer-selector-spill.log`, `intermediate-predicate-compile.log`, `envelope-r0.inc` and `prepare-r0.py` retain preliminary CPU build evidence. The first direct elision and later peer-selector attempt failed the no-spill check. The final source reuses the intermediate state destination pointer for the diagnostic predicate and forms the candidate byte address with integer arithmetic before the guarded store.
- `probe.py` resolves the synthetic entry point from the mounted candidate library. Only the owner should replay the physical test inside the existing isolated M6000 benchmark lease. The timed run requires the existing CUDA runtime image, GGML base library and a candidate matching the frozen digest. No model weights or prompts are used. `release.sh.in` shows the owner harness. It relies on the campaign lock and local admission helpers.
- Run `sha256sum --check --strict SHA256SUMS` and `python3 -B replay.py` to verify the public-safe packet without device access.
