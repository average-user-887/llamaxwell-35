# Evidence manifest

Prepared after the independent Q3 rollback and failed serializer receipts entered the experimental branch. Base native runtime is the previously published N100 r1 c973 build. The Q4 attention patch is relative to its inherited Q3 R2 source, already published in the same history.

The three receipt JSON files and full chronological trace JSONL files retain every accepted, rejected and output-boundary event, host counter snapshot, stream clock milestone, run status and mapped build evidence. Unavailable per-cycle clocks remain null. The complete native comparison reproduces the table and ID divergence. The separate Q4 operator receipt retains every interval and numerical geometry. Compile metadata records executable/library byte identities, resource data and prior instruction equality.

Data values, private prompt/output identity digests, local host paths, addresses, credentials and token IDs are excluded. The benchmark model and exact executable and library hashes are kept for reproducibility. Commands require the established bench harness, admitted local GPU and separately provided fixture.
