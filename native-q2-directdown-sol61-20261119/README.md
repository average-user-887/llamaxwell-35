# Direct Phase C down loads on Quadro M6000

The exact two-row, eight-expert MoE operator passed its technical checks and missed its predeclared speed gate. All four mirrored comparisons were required to save at least 13.1 microseconds per complete graph; observed savings were +6.072, +21.792, −41.195 and +6.955 microseconds. The candidate stays outside the retained model stack. This is an operator experiment, not a model-throughput result.

| Experts shared between rows | First paired saving | Reverse paired saving |
| --- | ---: | ---: |
| 0 of 8 | +6.072 µs | +21.792 µs |
| 5 of 8 | −41.195 µs | +6.955 µs |

Positive savings mean the candidate finished sooner. Both modes used one executable, the same candidate DSO, graph, seeded inputs and fixture weights. Each fixture had two eight-call warmups and four measured windows of 32,768 synchronized graph calls in mirrored order, for 262,144 measured calls overall. Every raw interval, including warmups and slow intervals, is retained in [perf.log](perf.log) and [result.json](result.json). Graphics and memory clock observations are unavailable. The observed interval variation cannot be attributed to a particular cause from this evidence.

Each fixture checked both ordered top-eight expert lists against the independent CPU and generic GPU router references. All 4,096 finite output words matched the retained cohort path bit for bit, and the candidate repeat matched. Both kernels physically admitted two 512-thread CTAs per each of 24 SMs. Counted dispatch and handled second callbacks agreed with the actual calls. Runner and cleanup exited zero; the whole stage took 50 seconds under its 180-second cap. See [check.log](check.log), [portable-receipt.json](portable-receipt.json) and [status.txt](status.txt).

The candidate replaces Phase C's shared-memory weight transpose with direct aligned nine-word read-only packets. All eight routed experts and the shared expert remain active; dot chains, weighted combines, butterfly order and residual add are preserved. The down loop shrank 774→689 static instructions, scalar LDS 33→2, STS.128 seven→zero and XMAD 35→15. It trades seven vector global loads for 27 scalar loads. Both logical weight payload and checked arithmetic counts stay unchanged. The added kernel uses 64 registers and zero stack/spills. All 17 original kernels retain 46,032 instruction/scheduling words. See [baseline source](occamy-fused.base.cu), [candidate source](occamy-fused.cu), [patch](candidate.patch), [build evidence](build.json), [compiler log](build.log) and complete disassembly.

The unchanged R1 control byte-reproduced 369c6b05; the timed candidate was 0dc9fe44 and operator 581752b3.
