# Two-row Phase A router weight reuse

The direct control is the current native eight-expert Q2 CUDA library 9e999bca, including the fast sparse selector and Q8 GDN. Replacing its two-row MoE object adds one opt-in kernel. The 17 previous MoE device functions have identical instruction and scheduling words. The contiguous selector object is identical in both links. The new kernel uses 64 registers, zero stack or spill bytes, 96 static and 39,424 dynamic shared bytes. Every launch must demonstrate 24 SMs with two resident 512-thread blocks per SM. The signed counter for this exact path must agree with all 800 timed or warmup dispatches across the two modes.

Each of 48 CTAs computes the original normalized activations for both rows in separate padded slots. Every quarter router task has one warp owner, which loads the same 16 weight elements per lane and computes two independent accumulators in the original FMA and XOR reduction orders. The original local row and peer row write their own partials. All producer threads issue a device fence before the separate 48-block barrier. A third scratch record provides only its separate count and generation slots, zeroed in the original strided memset with a third row. Original row-local work distribution, ordered routing, eight retained experts, activation and down projections stay intact. This changes normalization work, the number of weight loads and full-grid arrival costs. No traffic savings are assumed to translate to speed.

The fixture toggles GGML_CUDA_OCCAMY_MOE_Q2_ROUTER at the typed native two-row dispatch. Check mode requires independent and 5/8-overlap inputs, exact ordered routes, two finite 2,048-value outputs, and an exact candidate repeat. Timed mode checks ordered four mirrored intervals per fixture with 96 repetitions per interval after two warmups. Each pair in each fixture must save at least 9 µs relative to cohorts. The paired fixture uses a single candidate library with opt-in off or on. Its original device path is verified against the directly relinked actual control. No change to sparse selection is exercised by this isolated MoE operator.

release.sh --check uses only CPU, and --run is for the root's current sole M6000 lease. The maximum physical interval is 180 seconds and the root supplies its cutoff. Set GGML_CUDA_OCCAMY_MOE_Q2_ROUTER=1 with the existing native cohorts enabled only for a separately admitted model trial after the operator gate passes.
