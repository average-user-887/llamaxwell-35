# Reproduce and verify the R2 packet

R2 inherits the exact mapped artifacts, supervisor and decoder from the [published R1 source and shadow qualification](https://github.com/average-user-887/llamaxwell-35/tree/68caf44b5f6e7ca331da88354111a6d89221484b/native-80k-compact-r1-20261119). `model.py.patch`, `release.sh.patch`, `prepare.py`, `source-pins.json` and the owner manifests record the profile change and byte identities. `typed-cli.json` records the one environment delta and the typed speculation suffixes. The already-published [isolated b71 down4 pair](https://github.com/average-user-887/llamaxwell-35/tree/32be2864551de6fc0b230cdfeda1fb57ffae618d/native-80k-down4-20261119) is a separate software profile.

Verify `sha256sum --check --strict SHA256SUMS`, then run `python3 -B replay.py --results results.json` and `python3 -B verify-reconciliation.py`. These checks require only the portable files. They check phase boundaries, actual launch counts, guard and readback byte accounting, archived-trajectory equality and timing arithmetic. The baseline runtime and exact private fixture are required for owner replay against the original archive.

For owner regeneration, run `python3 -B r2-evidence.py --owner-card OWNER_R2_CARD --r1-pair-source VERIFIED_R1_PAIR_PACKET --receipt shadow SEALED_SHADOW --receipt native SEALED_NATIVE`. The helper checks the exact publisher-side [R1 pair accounting source](https://github.com/average-user-887/llamaxwell-35/tree/ef15661db0598e4ed233ed4ca0940a93e2d1b2cb/native-80k-compact-r1-pair-20261119) by manifest. To add a validated serial control, append `--receipt serial SEALED_SERIAL --pair SEALED_SERIAL SEALED_NATIVE --controller-pair CONTROLLER_PAIR`. The source, registry paths and all owner receipts stay private. `export-model.py` replays the original terminal validator and emits allowlisted numerical and equality fields.

The delivered decode rate uses all emitted IDs divided by the server decode interval. The raw server rate uses the same interval and one fewer decode step, because the first token comes from the last prompt batch. Warm client split rates use measured gaps between token-bearing SSE checkpoints. Wall time measures the full client request. The shadow arm retains full logits for independent row comparison and is excluded from the timed performance pair.
