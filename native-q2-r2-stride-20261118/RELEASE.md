# Two-row retained attention with fixed token strides

The direct baseline is the 9e999bca selector DSO. The candidate combines the previously measured four-block tiled probe from 58bab12 with a new opt-in retained-attention kernel on aligned 80,128 through 83,200 keys, Q2, two KV heads, a 512-byte head pitch, equal 1,024 or 2,048-byte K/V token pitches and twelve original splits. All 35 device functions from 58bab12 remain bit-identical, including the original Q2 retained attention. The unchanged harness replays four fixed-input processes in ABBA order at 81,920 keys. Both arms enable stable top-16. The candidate arms additionally enable the tiled probe and fixed-stride retained attention.

The kernel keeps the original four unit lanes, 512 threads, 24 total blocks, each warp's token and FMA order, original running softmax/weighted-value arithmetic, and both original combines. It loads every one of the same four K and four V vectors using constant token increments over a 64-bit base and a bounded unsigned byte offset. It keeps the sixteen immutable far-block IDs in the lanes of each warp. A single warp accounts for all eight peer warps that independently validated the same immutable row/head plan. The original cold/invalid fallback still traverses every key. Only the opt-in shape takes the new code. An untimed first-call diagnostic exercises one fallback directly.

Offsets remain below 171 MB even at the largest supported pitch and width. The physical four-key vector loads, arithmetic opcode counts, resource usage and unchanged function words are checked from machine code by verify_build.py. Each variant has zero local spills. The original inner loop has 610 instructions and 76 XMAD. The specialized loops have 495 instructions and zero XMAD. These counts quantify compiled work. Runtime savings require the physical test.

The existing fixed fixture has 2,048-byte padded token rows. The model cache source implies 1,024 bytes for two 256-element F16 heads. During the standalone diagnostic only, each candidate repacks all K and V rows into the model pitch on device and compares raw output, 98,304 split-value words and 768 max/sum words against the original generic kernel on the padded source. The same process also checks original scores, four plans, all 8,192 primary outputs, invalid-mask metadata and one forced full-key invalid-plan fallback. Timing remains whole-operator timing on the original fixture. Actual model dispatch, behavior and timing require a subsequent run.

The GPU lease owner supplies the M6000 UUID through N3_GPU and the live lease deadline through ROOT_GPU_DEADLINE_EPOCH. The runner keeps a 180-second cap, checks the named GPU lock and idle state, and cleans up only its own labeled containers. It records Q2_R2_STRIDE_RECEIPT.
