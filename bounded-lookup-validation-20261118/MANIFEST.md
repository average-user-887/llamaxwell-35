# Package manifest

| File | Contents |
|---|---|
| `README.md` | Same-build controls, bounded repeats, cache and work matching, and reproduction settings. |
| `evidence.json` | Allowlisted runtime and source fingerprints, scalar measurements, and exactness verdicts. |
| `SHA256SUMS` | File checksums for the README, evidence, and manifest. |

The allowlist covers public commits, patch/source/model/image/binary/input and receipt fingerprints, GPU product details, typed argument settings, workload and cache counts, observed verifier widths, proposed and accepted counts, checkpoint replay widths, timing and rate scalars, exit status and exactness verdicts. The original prompt and response material stay with the private run receipts.
