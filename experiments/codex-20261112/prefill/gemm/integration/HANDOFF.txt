NARROW SUPPORT
SM52 only; Q/output FP32, K/V FP16; head dimension 256; 16 query heads / 2 KV heads.
Single sequence, contiguous [D,H,Q,1] output; 64-1024 queries, 4096-98304 keys.
Arbitrary query tails are zero-packed and excluded from output writes.
Arbitrary key tails use a separate final PV GEMM; no padded or truncated KV reads.
Q/K/V row and head strides are consumed directly; dim0 must be contiguous.
Optional additive FP16 mask uses actual row stride, with ne0>=keys and ne1>=queries, ne2=ne3=1.
No sinks, ALiBi/max_bias, softcap, or sparse n_kv_max. Unsupported cases fall back.
All-mask-negative-infinity rows produce exact zero rather than NaN.
Scale is read from the actual GGML operator; all GEMMs and reductions use FP32.
Reduction order differs from baseline, so this is not bit-exact.

ALGORITHM / MEMORY
Converts FP16 KV to FP32 once per operation; packs 8 GQA heads into 512-column GEMMs.
64-query tiles; QK SGEMM, full-context masked softmax, split-4096 PV batched SGEMM, final reduction.
One fixed pool slab: 633341056 bytes (604.0010986328125 MiB), independent of actual supported Q/K.
Breakdown: FP32 KV 384 MiB, packed Q 16 MiB, scores 192 MiB, PV partials 12 MiB, pointer tables 1152 bytes.
Uses the backend's current CUDA stream, cuBLAS handle, and existing 4 MiB cuBLAS workspace.
Does not create events or synchronize in the hot path; existing allocator/handle creation can perform their normal initialization.
First use logs shape, mask stride, split tail, requested slab bytes, pool allocation bytes, and existing cuBLAS workspace bytes.
The context's VMM pool may already have reusable capacity; real high-water VRAM requires root measurement.

PROBE PURPOSE
The probe invokes the actual integrated shared-library dispatcher, not a separate copy of the candidate.
Defaults: Q=1023, K=98048, one ABBA timing round after correctness.
Tests padded/noncontiguous Q/K/V rows and heads, mask row padding, finite additive mask bias, scattered masked holes, 128 terminal masked keys, arbitrary query tail, and 3840-key PV tail.
Uses a non-default scale of 0.09375.
The last query row is fully masked; it is independently required to produce all zero.
The stock reference produces 0/0 on that row, so it is excluded from ordinary error statistics only.
All other outputs must be finite; reports max absolute error, floored relative error, RMS, and bit differences.
An output canary must stay unchanged. Safety thresholds maxabs<=1e-4 and RMS<=1e-5 are not model-quality acceptance.
Requires --gpus explicit M6000 UUID and LD_LIBRARY_PATH pointing to candidate build/bin.
