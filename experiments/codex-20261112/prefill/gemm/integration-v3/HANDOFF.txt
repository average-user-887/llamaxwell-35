DELTA FROM FROZEN V2
Only the masked-softmax kernel changes to two-pass online max/sum, plus its first-use version label.
The first pass computes each thread's stable running maximum and normalized sum; block reduction reconciles the thread maxima and sums.
The second pass reads the same score plus actual additive mask and writes normalized probabilities.
All-masked rows explicitly write zero when the reduced denominator is zero.
Query padding guard, full key iteration, mask byte stride, PV key tail, FP32 GEMMs, and all support guards are unchanged.
No synthetic end-causal position is assumed.
Finite score values with finite or negative-infinity additive masks are supported. Positive-infinity/NaN masks are not newly qualified.
