Both runs report ordinary comparison nonfinite=0, candidate all_masked_nonzero=0 and output_guard_changed=0.
An eighth selection is deliberately all-masked: all 16 candidate samples are finite zero, while the direct stock tile has 16 nonfinite samples. These stock values are explicitly flagged and excluded from normal error aggregates; zero-valued error placeholders are not zero-error claims.
Independent CPU recalculation from all 112 per-sample error records reproduces each reported maxabs, RMSE and closer-count.
Inputs are the same seeded synthetic FP32 Q / FP16 K,V, actual-scale additive-mask fixture used by both operators, including finite biases, holes, padded strides, query tails and key tails. They are not extracted model activations.
The reference uses FP64 QK, softmax and PV on CPU, not GPU FP64. FP64 is a high-precision reference, not exact real arithmetic.
Only sampled dimensions are compared to double. The full output is checked against stock separately. No timing claim follows from these zero-round diagnostic invocations.
Closer synthetic arithmetic can still change quantized activations, MoE routing and recurrent/KV state, so it does not erase the observed real-model distribution drift.
