CPU-only build script: build.sh. It reads frozen v4 source/build read-only and writes only this directory.

WHAT IT DOES
Uses the same seeded Q/K/V, padded row/head strides, finite additive mask bias, masked holes, masked terminal keys, query/key tails, and output canary as the integrated probe.
The scale is the actual model's0.0625 for BOTH GPU operators and the CPU reference.
Launches stock tile and actual candidate shared-library dispatcher once, then copies both outputs to CPU.
CPU reference computes FP64 dot products, max-shifted exp/sum, and V-weighted sums from the exact same FP32 Q and FP16 K/V/mask values.
Seven normal query/head selections plus one all-masked selection;16 output dimensions each. No GPU FP64 is used.
Per-sample and per-selection JSON, plus one double_summary record report error versus FP64 for BOTH paths.
The all-masked row's stock nonfinite values are flagged, not used in normal aggregate statistics; candidate must be zero.
The standard whole-operator finite/error/canary safety checks still run before this diagnostic.
CLI unchanged: Q K timing_rounds optional_output_dump_path. Use0 timing rounds for minimum GPU time.

Use /tmp as the container working directory: root's initial read-only /w launch failed before CUDA initialization; the /tmp retry succeeded.
Serialize all GPU launches under the parent's gpu-bench.lock; this worker has not run the GPU probe.
Extract double_summary for a compact accepted-result packet. Raw per-dimension records should remain saved.

LIMITS
These are synthetic operator inputs, not extracted real-model tensors.
FP64 is a high-precision numerical reference, not exact arithmetic.
A candidate closer to FP64 here does not prove model-quality equivalence, and a larger error does not alone locate the16K model drift.
The raw model-quality audit and smallest controls are recorded in AUDIT.txt.
