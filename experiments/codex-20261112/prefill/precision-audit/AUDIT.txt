PRECISE FLOATING-POINT DIFFERENCES
1. Stock multiplies Q elements by scale before QK; SGEMM applies alpha after its dot accumulation. For actual scale0.0625 this is a power-of-two placement change and should commute for normal, non-overflowing FP32 values; dot accumulation order still differs.
2. Stock uses FATTN_KQ_MAX_OFFSET=3*0.6931, approximately ln8, in the running softmax maximum. The candidate uses the unshifted maximum. Exact-real probabilities are identical, but FP32 exponent scaling and underflow behavior are not.
3. Stock repeatedly rescales the unnormalized PV accumulator as its running maximum changes, then normalizes at output. Candidate computes normalized probabilities first, then multiplies V by those FP32 probabilities.
4. Candidate PV uses4096-key GEMM partials, followed by ascending partial reduction. Stock accumulates through its own tile/lane order across the KV sequence.
5. Stock mask scan can skip fully masked trailing256-key blocks. Candidate evaluates the full declared K extent and applies the mask. These are equivalent for finite Q/K/V and finite/-inf masks. Startup KV storage is explicitly zero-cleared in llama-kv-cache.cpp:293; nonfinite data remain unqualified.
6. Intentional edge difference: a completely masked real query row returns zero in the candidate; the direct stock tile returns0/0. Normal causal model rows have at least one visible key. Padded candidate query rows are never written.
Source pointers: fattn-tile.cuh:656,689,696,711,935,997,1108; fattn-common.cuh:21,711,1157.

WHY THE QUALITY DIFFERENCE IS STATE DRIFT, NOT A NEW DECODE PATH
Both quality16 runs split the last prompt at15356,16380,16384 tokens, leaving a4-token final tail.
That final tail is below the candidate's64-query guard, so row0's final attention operation uses stock dispatch on state previously produced by candidate prefills.
Rows1..15 each process a single new teacher token; they also cannot enter the GEMM path.
The observed differences therefore propagate through stored KV/recurrent state and subsequent model operations. Quantized activations and MoE expert selection can amplify small perturbations; that is a hypothesis, not a measured attribution.
