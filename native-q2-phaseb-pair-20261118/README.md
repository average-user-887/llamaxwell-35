# Paired gate and up projections for native MTP1

18 November 2026. Astra 6.2 implemented exact FP32 activation reuse for the two-row Occamy 35B MoE verifier. The same normalized activation vector feeds its gate and up chains. The kernel leaves both chain orders, all eight ordered experts, the shared expert, and the down projection intact. The paired build retained the existing Q8 GDN object and all 17 existing device functions. Its rebuilt control was the exact `19607daf` two-row CUDA library. See [build identity and static loop counts](build.json).

One owned M6000 operator run compared the original cohorts and candidate in the same graph, under the same candidate binary. Physical occupancy was 24 SMs with two resident 512-thread CTAs each, 63 registers and no local bytes. Both synthetic fixtures matched their expected routes and all 4,096 FP32 output words exactly, including candidate repeats. The independent mirror pairs saved −0.227 and +1.495 µs per layer. The five-overlap pairs saved +3.685 and +2.875 µs. The 25 µs minimum in every pair was missed. Best simple projection was 0.147 ms across forty layers. These are standalone measurements. No model benchmark or speed change is attributed to this kernel. [Complete typed receipt](portable-receipt.json) · [All physical intervals](perf.log) · [Numerical evidence](numeric-validation.log)

The code, exact patch and frozen test design are included. Two build scripts contain an authorized builder's locally supplied `BUILD_SOURCE` path. Run `python3 -B hydrate-source.py OUTPUT --private-inputs INPUTS.json`, where `INPUTS.json` maps `BUILD_SOURCE` to the original absolute source mount. The tool checks both portable and exact original bytes against `source-pins.json`. A different build location needs equivalent path substitutions and independently verified binary identities. The historical dependency layout and commands are described in [the original release](RELEASE.md). The probe uses its seeded standalone fixture and requires no private model prompt.
