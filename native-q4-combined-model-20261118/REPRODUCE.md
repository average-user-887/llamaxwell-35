# Reproduction

Run `sha256sum -c SHA256SUMS` and `python3 -B verify-package.py` from the packet. The verifier uses the six public receipts and chronologies, verifies every algorithm source fingerprint and recomputes the host deltas. The serial and three native long arms share CUDA abe7dcfdbf2d7df0b31b5478212f3234ffdd8e2b8f9a077c0a216b2e32865aae and the same observed executable, server implementation and host observer.

The staged sources use the original campaign layout. Place the model files in resume-q4-combined-native and the rollback files in resume-q4-combined-rollback alongside the source checkout, compiled GGML objects, typed experiment runner and owner-provided fixture materials named by the release. Supply private values locally through `python3 -B hydrate-source.py OUTPUT --private-inputs LOCAL.json`. Without the optional file the command verifies portable copies and lists the required key names. It verifies the original source hashes after local substitution. Names within containers such as /candidate and /fixture are executable interface paths. The prior public native-q4-moe-operator-20261118 and native-width-controls-q4-20261118 packets contain the source deltas for the two observed CUDA objects.

In the model directory run `./relink.sh` to reproduce the two reference libraries and the combined library from the pinned 147-object build and its two replacement objects; the link lines are in link.sh. Then run `./build-audit.sh`, `./check-observer.sh` and the GPU owner's admitted `./release.sh --run ARM`. The six ARM values are smoke-off, smoke-on, serial-on, depth3-off, depth3-attn and depth3-combined. The 2K bounds are 190 seconds; 80K bounds are 430 seconds. Only the two short modes submit the independent arithmetic request. Use the original operator's manifests with the matching private inputs, route and runtime.

For rejection in its own directory, `./build.sh` builds the CPU harness and `./release.sh --run` starts the separately bounded 190-second GPU trial. The private serializer retains active convolution, recurrent and attention-KV payloads. Its checks validate the stream envelope and compare every logical byte. After a run, `python3 -B analyze.py RECEIPT/raw` checks the private records and `python3 -B safe-report.py RECEIPT` retains the anonymous numerical and timeline evidence. Individual reset phase wall times were unavailable. The public files carry no active state bytes, generated token IDs or content digests.
