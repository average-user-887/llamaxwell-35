# Package manifest

| File | Contents |
|---|---|
| `README.md` | Matched cold and warm results, midpoint recall, separately measured long warm replay, and the exact server configuration change. |
| `evidence.json` | Allowlisted scalars, comparison verdicts, and reproducibility fingerprints. |
| `SHA256SUMS` | SHA-256 checksums for the README, manifest, and evidence. |

The allowlist covers published commit IDs, source/model/image/binary fingerprints, prompt/template fingerprints, source-receipt fingerprints, GPU model and architecture, server flags and effective geometry, bounded workload dimensions, timings, rate definitions, cache counts, acceptance counts, mismatch positions, dispatch shapes, wrapper status, and exact-match verdicts. The midpoint output fingerprint is represented by its independently verified equality verdict.
