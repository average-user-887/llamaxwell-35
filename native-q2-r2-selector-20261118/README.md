# Exact two-row sparse R2 selection on Quadro M6000

At 81,920 keys the opt-in selector reduced the whole two-row attention operator from 246.43 to 203.48 μs and from 246.57 to 203.47 μs. The two warmed mirrors saved 42.95 and 43.10 μs, both above the preregistered 23 μs gate. All four processes produced identical 32,768-byte attention outputs and identical plans. Each candidate warmup also independently replayed the original R2 operator on the same inputs and checked four plans, 1,280 scores and 8,192 output words against the candidate with zero differences. Runner and cleanup both returned zero.

Each CTA ranks one query row and KV head. Each warp sorts 32 scores and retains its top 16. A four-stage parallel merge finds the stable global top 16 by descending score and ascending block ID, then writes those IDs in ascending order. The original R2 mask and score validity rules, probe, attention math and output combine are preserved. The option `GGML_CUDA_OCCAMY_FA_Q2_R2_TOP16=1` applies on the existing Maxwell sparse R2 route with two query rows, two KV heads, and aligned key widths from 80,128 through 83,200. CPU parity passed 835 fixtures across those 13 widths. Physical evidence here is for 81,920 keys. Ten equivalent calls project a minimum 0.4295 ms saving. Model latency and model output parity require a separate evaluation.
