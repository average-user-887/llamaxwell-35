# Package manifest

| File | Contents |
|---|---|
| `README.md` | 80K cold and warm results, 2K graph diagnostics, and the exact setting change. |
| `evidence.json` | Allowlisted build and runtime identity, verified measurements, output equality verdicts, and graph counts. |
| `SHA256SUMS` | SHA-256 checksums for the README, evidence, and manifest. |

The allowlist covers public commits and source/build/model/image/binary/receipt fingerprints, public GPU product details, named numeric runtime flags, configured dimensions, request and cache counts, draft and rejection counts, phase graph counts, device offload counts, timing and rate scalars, technical exit codes, and exact-match verdicts. The runtime identities use library basenames and hashes.
