## ptxas (sm_52) and occupancy
| kernel | regs | spill | smem | blocks/SM (256 thr) |
|---|---|---|---|---|
| hs_ar (F16, unchanged) | 118 | 0 | 33,664 | 2 |
| q8 <0,1> | 118 | 0 | 33,664 | 2 |
| q8 <1,0> | 121 | 0 | 33,664 | 2 |
| q8 <1,1> | 127 | 0 | 33,664 | 2 |

- Every q8 kernel is at or under 128 registers. Registers limit occupancy to 65536 / (128 x 256) = 2 blocks per SM. Shared memory, at 2 x 33.7 KB, also fits 2 blocks.
- That is 16 warps per SM, the same as the F16 kernel.

## GPU gates: READY, NOT RUN (`gates/`)
- Run: `Q8N_GPU=<gpu> Q8N_UNLOAD_URL=<lab-endpoint>/api/models/unload/qwen36-35b-moe gates/run-q8n-gates.sh`
  - Options: PARTS, DOCS, ORDER, EXTRA_ARMS, SMOKE=1.
  - The script holds flock gpu-bench.lock and sends an unload POST for qwen36-35b-moe only.
  - It aborts if any compute apps are on the GPU.
  - It refuses MAXWELL_GRAPHS and MAXWELL_GEMM.
  - It uses nq8n-* containers only and removes them on exit.
- Exactness (`q8n_rows_harness.py` + `q8n_analyze.py`):
  - Tool: `q8n_rows` (built), which is g1c_rows with separate K and V types.
  - Method: G1c teacher-forced rows. Buckets 4096 / 32768 / 98304, NR 64, 8 docs.
  - Arms:
    - G = generic q8
    - N = native q8
    - Gp = noise
    - F = F16 context
    - X = same-cache compare (FA=2)
    - Nk / Nv = mixed (optional)
  - Gate: N vs G, dmean <= +.0010 and same-top >= -0.3 pt in every bucket.
- Server (`q8n_srv.py` + `q8n_srv_analyze.py`):
  - Order and arms: ABBA x3 (FQQF,QFFQ,FQQF). F = F16 with the D0 slots restored read-only. Q = q8 native. G = generic q8 (optional).
  - Units:
    - both_deep: 98000 + 90000 tokens, n=48 on both slots concurrently
    - single_98k
    - append_4k: 90K + 4096-token prefill
  - Peak VRAM is recorded per unit and per session.
  - q8 slots: built by prefill in D0 shape (s0 n=24, s1 n=1) on the first q8 session and saved to `gates/slots`, then restored.
  - A unit is invalid if a restored decode re-prefills (prompt_n >= 64).
- The analyzers were self-checked on synthetic data only.
