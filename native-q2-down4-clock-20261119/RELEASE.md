# Longer clock windows for the same four-row MoE operator

This card retimes the previously measured four-row operator after the independent compact readback screen. The original control and candidate CUDA functions, data, device object, DSO, graph, input, resident geometry and diagnostic checks are byte-identical. The fresh operator keeps the warmups and the A/B/B/A, B/A/A/B ordering. Each timed interval now covers 98,304 synchronized calls, three times the prior length. Every measurement still requires its own original Fleetdash source timestamp inside the window. The host allows eight seconds for delayed final samples. At observed rates, the eight measured windows total approximately 124 seconds, with approximately three seconds of warmups and eight seconds of grace. The entire operator card retains the prior 180-second cap.

The prior independent clock evidence covered two complete mirrors; this card requires SM and memory median ratios no greater than 1.02 in all four. The historical standalone gate remains 13.1 µs/layer in every comparison. The secondary screen for a possible combination is 2.3 µs/layer in every mirror with the same numerical, physical dispatch and complete clock gates. At full transfer, 0.092 ms across forty target layers plus the separate 0.431103 ms readback operator lower bound would cover the historical 0.52128 ms gap. The two operators have not demonstrated combined model transfer. A positive secondary screen alone cannot promote either overlay. An eventual model comparison needs its own exact merged software identities, witnesses for both changes and same-build serial control.

Use ./release.sh --check offline. Only the GPU owner may run the card with the admitted N3_GPU and sufficient ROOT_GPU_DEADLINE_EPOCH. The card prints Q2_DOWN4_CLOCK_RECEIPT and records any timing, observability or numerical failure. The source templates and actual performance decision are preserved locally.
