# Package manifest

| File | Contents |
|---|---|
| `bounded-lookup-r1.patch` | Byte-identical cumulative corrected patch for the published FA2 plus cache-only source. |
| `README.md` | Applicability, build and replay settings, request field contract, and measured results. |
| `evidence.json` | Typed settings, scalar receipts, validation outcomes, and provenance digests. |
| `SHA256SUMS` | SHA-256 checksums for the patch, README, evidence, and manifest. |

The allowlist covers public commits and the donor's upstream repository-relative path, source/model/image/binary/input and receipt digests, GPU product details, typed flags and request dimensions, proposed and accepted counts, restore shapes and intervals, timing and rate scalars, cleanup and HTTP statuses, and exactness or semantic verdicts. The patch and schema use the field name `token_ids`. Request contents are supplied by the operator.
